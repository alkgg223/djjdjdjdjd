# Guns & Warfare (gunsmod) — Minecraft 1.21.1 / NeoForge 21.1.264

## تحويل المشروع إلى ملف jar

**الطريقة 1: GitHub (من الهاتف)**
1. أنشئ مستودعاً جديداً وارفع محتويات هذا الملف المضغوط إلى جذره، بما فيها مجلد `.github`.
2. افتح تبويب **Actions**، ثم **Build mod**، ثم **Run workflow**.
3. بعد انتهاء البناء (بضع دقائق) نزّل `gunsmod-jar` من أسفل صفحة التشغيل. بداخله `gunsmod-1.0.1.jar`.

**الطريقة 2: كمبيوتر عليه JDK 21**
```
./gradlew build
```
يظهر الملف في `build/libs/gunsmod-1.0.1.jar`.

## التحكم
| الزر | الوظيفة |
|---|---|
| الضغط (هجوم) | إطلاق النار (اضغط مطولاً للأسلحة الأوتوماتيكية) |
| الاستخدام (كلك يمين) | تصويب: نقرة للتبديل، أو اضغط مطولاً |
| R | إعادة التعبئة |
| V | تبديل المقعد في الجيب |
| H | بوق الجيب |
| G | أمر للسائق البوت بالتوجه إلى المكان الذي تنظر إليه |
| شفت + كلك يمين بالريموت | تحديد الهدف على أي بلوك |
| كلك يمين بالريموت | فتح لوحة الإطلاق |
| شفت + كلك يمين على الجيب | الجلوس في مقعد الرشاش |
| يد فارغة على بوت أخضر | اتبعني / ابقَ مكانك |
| شفت + كلك يمين على بوت | محرر البوت (سلاح، درع، أوامر) |

## الوصفات الأساسية
- سبيكة فولاذ = حديد + فحم (بدون شكل)، أو حديد في الفرن العالي.
- طاولة صنع الأسلحة: `SSS / ICI / P P` (S فولاذ، I حديد، C طاولة صنع، P خشب).
- باقي الأسلحة والذخيرة والإضافات والصواريخ والجيب تُصنع من داخل طاولة صنع الأسلحة.
